# anycreo.com

Marketing site for Anycreo. Plain HTML/CSS/JS, no build step. Served by GitHub Pages from `main`.

- `index.html` page, `styles.css` design tokens + layout, `app.js` hero preview, pricing toggle, scroll reveal.
- `CNAME` holds the custom domain.
- Preview locally: `npx http-server -p 8642 .`
